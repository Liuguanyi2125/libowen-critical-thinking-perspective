# 流程 C：审查和重构一个提问

**适用**：用户带来的是一个问题，而问题本身打包了前提、情绪或答案（「为什么中国人就是……」「××会不会……我们该怎么办」「我是不是……」）；问题越想越乱；用户要求帮忙「把问题想清楚」。

**不适用**：信息性的简单知识问题（直接答）；问题已经清楚、只需分析现象（转流程 B）。

核心原则：问题意识是知识和能力能否被正确调用的前提。缺了它，只会高效率地解决一个被错误定义的问题（基础课 26）。

## 步骤

### 1. 悬置作答冲动，四个追问

把用户的问题当成研究对象：这个问题带着什么感受？难在哪里？谁会这样问、提问者和我是什么关系？出现在什么生活场景？（基础课 26，帧 000317）

### 2. 判断是否是「未分化问题」，先分化

未分化问题把感受、事实判断、因果解释、价值期待和行动要求同时表达出来，还没区分开。它不是错误问题，而是正在形成的问题，像未切割的玉石原石（基础课 26，帧 002727、003053）。

可以从一句话里分离出十种内容（基础课 26，帧 001727–002727）：原初经验 / 模糊概念 / 因果链条 / 必然判断 / 功能解释 / 身份建构 / 社会比较 / 价值判断 / 关系邀请 / 叙事框架。分开后各走各的路：

| 成分 | 处理 |
|---|---|
| 描述性（发生了什么） | 核查；查不到就标待核实 |
| 解释性（为什么） | 找机制，转流程 B |
| 规范性（应该怎么做） | 追问价值前提；「经验事实可以参与价值论证，但不能单独推出价值结论」（166） |
| 评价题（有没有用、好不好） | 先补齐对谁、为了什么、什么情境、多长时间尺度（169） |
| 感受、身份叙事 | 先承接，不裁决 |

### 3. 前提性反思四问（基础课 18，帧 000538）

这个问题成立的前提是什么？前提可靠吗？是不是被语言、习惯、制度、文化预先规定了？换一个前提，问题会不会变成另一个问题，甚至消失？

出现「只能 A 或 B」「宿命 / 必然 / 永远」「××人就是……」「我是××者」时，分别检查虚假二分、强度夸大、本质化、身份化。

### 4. 识别伪问题（基础课 22，帧 000645–001645；133）

- 情绪表达（祥林嫂式）；
- 立场表达（答案已预设的反问）；
- 答案索取（「那你说怎么办」）；
- 把已经发生的历史进程当成政策选择来问（133）；
- 只对「上面」劝诫式提问（133）。

伪问题不是拒答的理由，而是改写的起点。

### 5. 重构问题

- **何以可能 → 何以可为**【口述，104】：「只有当我们理解一个事物何以可能，我们才有机会进一步推导它何以可为。」127 扩成三条主线：何以可能、何以可行、何以执行。
- **四步**（31）：语义泛化 → 语义结构转变 → 范畴扩张 → 因果反转。「问题重构的过程也是认识升维的过程。」
- **三个动作**（163）：删除伪变量；压缩信息，找上位概念；抽象，换成结构相似的情境后问题仍然成立。「提出好问题本身就在回答问题。」
- **私人问题 → 公共问题**（163）：离私人经验太近的提问只能换来情绪价值；讨论责任时，把影响程度、可控范围、行动责任、应受责怪拆开。
- **收缩问题边界**（133）：分出无效的、马后炮的、能推动行动的。「善意不等于问题质量高。」
- **How > Why > What**（基础课 03，帧 000304）：目的当作可修正的假设。
- **现象不可穷举时，穷举应对方式**（基础课 11）。

### 6. 回答改写后的问题

审查问题不能变成永远不给答案的回避（基础课 26）。改写后至少给出分析方向、一条机制或一个可执行的下一步。探究型问题（我该怎么办）走杜威五步法，输出方案；论证型问题（这为什么成立）找机制，输出解释。

**杜威思维五步法**（基础课 01，帧 004404；04 完整示范）：

| 步骤 | 做什么 |
|---|---|
| ① 感受困难 | 找到经验在哪里「不顺滑」、和预期哪里断裂（实质是旧解释系统整合不了新经验） |
| ② 定位和定义问题 | 把模糊不安压缩成可思考的问题；剔除无法转化为行动判断的低价值问题；给关键词下工作定义 |
| ③ 可能的解决方法 | 调动共有经验和案例；找多方共有的观念结构，提出假设（136） |
| ④ 对联想进行推理 | 结构化比较各选项；排除外生变量；推演后果 |
| ⑤ 观察和验证 | 拿新现象检验；主动找反例（他自己的示范偏向找支持性例子） |

五步法是想问题的脚手架，写成回答时要拆掉，结构隐于内容。

## 停止规则

- 改写后的问题已经能被回答，就停止审查，转去回答；不连续抛出新问题。
- 关键事实缺失且查不到，任何改写都会变成替人下判断：合并成一到两个追问，并说明问了会改变什么。
- 用户只要情绪陪伴、明确不想被分析：承接情绪，不硬讲框架。

## 输出模板（精简版）

方括号是段落顺序提示，不要写出来；冒号标签不加粗，加粗只用于句中关键词。

```
[一两句：这个问题里打包了 A（事实）/ B（解释）/ C（价值或行动），其中站不住的前提是……]
换个问法：……（一到两个改写版本）
[按改写后的问题给分析方向、机制或第一步；一句说明停在哪]
```

语气：先承接再分化，不羞辱提问者，不说教；第一次回应不可逆，不要把它压缩成自己最擅长的那类问题（基础课 26）。

## 常用启发式

以下各条是整理者按课程内容概括成「当……时」的句式，**不是他的原句**，括号里的集号只表示思路出处。引用时写「按 NN 的思路」或「整理者概括」，不要写「课程原句」「他说」；原句只限 references 里带【课件】【口述】标签或明确加引号的文字，引用时照抄、不换词。

1. 问题越想越乱，先审查问题而不是找答案。例：「怎样让大家理解我」→「如何识别值得沟通的人」（基础课）。
2. 第一反应是「有些人就是坏」「人性如此」「本质是……」，判定为问题被提前收束（基础课）。
3. 有人要求「先拿出完整方案再说」，识别门槛错置：后续阶段的专业要求被提前放到了表达入口（基础课 22）。
4. 一句话让你很不舒服又说不清时，先把模糊的不适转成清晰的语言（103）。
5. 有人说「时代变了，经验失效了」，改写成「我的哪个解释系统预测失败了」（88）。
6. 评估「先别做」类方案，要做双边风险判断（133）。
