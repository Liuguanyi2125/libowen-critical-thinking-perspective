# 流程 E：审一篇稿子

**适用**：用户给出文章、段落、作业、论文论点或长评论，要求看论证、改写或打分。来源：基础课 05、09 两次作业点评。

**不适用**：用户拿来的是别人的一套理论或世界观、要判断它站不站得住（转流程 A 的「闭环理论」分支）；只有一句话（转流程 A）；用户要的是标题、文案润色、营销包装（近邻任务，不套本流程）。

## 步骤

1. **判题型**：探究型（怎么办）必须给出可执行方案；论证型（为何成立）要找机制，不要给对策。
2. **句子分色**：经验句 / 判断句 / 情绪句，找出缺位的机制句和论点句。
3. **压成箭头链**：把文章「翻译」成一条论证链，标出断点（层次跳跃、个例 → 全局、相关当因果、事实直接跳到规范结论、社会 → 个体缺内化的桥）。压链时还要说出它靠哪种说理方式（劝诫、案例归纳、实证、矛盾分析、理论推演），换两种说理方式各压一遍，对比各自看到什么。断点按它自己那套标准判断；如果是别人的公共论证，长处和短处并列，不评好坏高下（按 102、115 的思路）。
4. **挑 2–4 个最关键的问题**，按下方「常见毛病」命名。
5. **给 1–2 处改写**：把判断改成可检验、可讨论的命题，并说明改写后需要什么证据。
6. **一句定位或评级**。如果是别人的公共论证，不给它打分，改为说清三件事：它还缺哪些各方都认可的事实，哪一段推理没有摆出来，同一个关键词在各方的框架里是不是意思不同（按 147、111 的思路）。

## 停止规则

- 默认只抓 2–4 个最关键的问题；用户说「详细批改」才逐句全展开。
- 不展开与评审无关的社会分析；稿子的论题本身值得分析时，只在结尾一句提示可以另走流程 B。
- 核心论点本身是本质化、不可证伪的「万能解释」时，先改论点，不再逐句挑小毛病（同流程 A 的停止规则）。

## 输出模板（精简版）

方括号是段落顺序提示，不要写出来；冒号标签不加粗，加粗只用于句中关键词。

```
[一句定位]
[箭头链：A → B → C，断点标在哪里]
关键问题：1. …… 2. ……
改写：原句 → 改写后（需要的证据：……）
```

## 评审标准

**篇幅**：默认评审正文 1500 字以内——分色或箭头链二选一、指出 2–4 个最关键的问题、给 1–2 处改写、一句评级或定位；只有用户要求「详细批改」时才逐句全展开，也不展开与评审无关的社会分析。

**总纲**：看你**如何**得出结论，不看你得出了**什么**结论。「思想有深度，但思维没有形状」不合格。逻辑与证据优先，文采和情感不计分。

**定义**：以分析、评价和推理为核心的写作；通过逻辑、证据和概念分析，揭示问题背后的假设、推理结构与价值取向。五步：提出问题 → 界定关键概念 → 分析论证 → 评估证据 → 提出新见解或改进（对应论文的引言 / 综述 / 实证 / 结论与展望）。

**先给句子分色**：经验句（以「我看到」为真）、判断句（以「我感觉」为真，以点代面）、情绪句（以「我愤怒」为真）。正文里应该剩下机制句和论点句。

**四步改写法**：从「我看见什么」到「我理解什么」；让读者从共情转向信服；满足公共讨论的需要（可证伪）；不是情绪爆发而是思想蓄压。例：「人都烂了」→「社会达尔文主义的竞争逻辑削弱了互信结构」。

**常见毛病**：情绪代替命题；判断缺论据；引用只做叙述不当证据；逻辑断裂（层次跳跃、社会→个体缺内化的桥、个例→全局）；意识流（语言没有承担思维的编码功能）；没有可被反驳的核心命题；串联式离题（每步合理，越走越远）；命题从方法论漂成价值宣言；哲学化写作没回答题目；把五步法直接写成文章骨架。

**动笔前判题型**：探究型（怎么办）必须给出可执行方案，反问题目合不合理就是跑题；论证型（为何成立）要找机制，不要给对策。

**四种建构路径及风险**：对齐-理论迁移（强行对齐）/ 抽象归纳建模（过拟合、黑箱）/ 升维框架（框架过大看似解释一切）/ 对象化展开（离题、工作量暴增）。

**逆向 vs 反向**：逆向是拆解、澄清、重构，质疑隐含前提，再回到原题正向回答；反向只是接受表层设定后反着答，像价值宣言。

**加分动作**：命题有张力且可证伪；逻辑链闭合；引入理论或方法；落回生活实践；补反方视角；文末自问必须自答；多用连接词帮读者过渡。高阶目标是「反思—重建，拿出新东西」，不是提出更多问题。

**评语方式**：先说定位（最严谨的一篇 / 最有哲学气质），再肯定亮点，再「如果非要我提修改意见」；把文章压缩成箭头链「翻译」给作者看；给出改写后的句子。
