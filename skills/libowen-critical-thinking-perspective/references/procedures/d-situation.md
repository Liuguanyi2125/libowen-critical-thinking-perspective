# 流程 D：拆一个人的处境

**适用**：「我明知道……还是……」「为什么我改不了」「被父母 / 领导 / 伴侣这样说，该怎么想怎么办」「道理都懂却做不到」「别人拿证据也说服不了」。

**不适用**：用户流露自伤、轻生、长期失眠或严重崩溃（先按 SKILL.md 安全规则 1 处理安全，分析放到后面且简短）；需要专业诊断或法律意见（只给框架，建议找专业人士）。

**本流程的边界**：只听到一方信息，不给家人、同事、领导下人格判断。教道不教术：可以讲清一致性、先手、情绪价值如何被利用，用于识别和自保；用户要用这些机制去控制、说服或拿捏某个具体的人时，不给操作步骤或话术，把问题改写成「分歧在哪、各自要什么、边界和协商怎么做」。

## 步骤

### 1. 承接，再结构化压力

先承接感受，不急着分析。然后把压力结构化：前提 → 结果 → 困境 → 追问（基础课 18）。用户只是想要情绪陪伴、明确不想被分析时，到这里为止。

### 2. 判断是「内部不一致」还是「外部评价」

**内部不一致**（改不了、想不通、被带着走）→ 走第 3 步。
**外部评价或关系压力**（被说、被要求、被比较）→ 走第 4 步。两者常同时出现。

### 3. 自我一致性诊断

自我一致性模型：鲜活经验冲击固有观念造成不一致，人必然要恢复一致；被动地恢复，会陷入诈骗、宣传、广告和各种谬误；主动地恢复，就能吸收经验、扩展信念之网（基础课 08、10、21）。

1. **哪种一致性在起作用**（基础课 08）：
   - **中式（社会）一致性**：「你应该……」，言行和过去现在未来的社会连贯性，显性控制、可反抗；
   - **心理一致性**（练习合集里也叫「自我一致性」）：「我感觉应该……」，思考、感受、需求、行动协调，隐性控制、难察觉；
   - **逻辑一致性**：观念间不矛盾，可训练。组合表结论：凡是有逻辑能力的组合都不撕裂，所以「逻辑可能是我们唯一的突破口」（基础课 08，帧 010723）。
2. **谁抢了先手**（基础课 10，先手矩阵 `p2/000030`）：思考、感受、需求、行动四者没有固定顺序，谁抢到先手都能带动其余三个。
   - **行动先手**：「先做了才相信」，预判后面的「信念补课」。两类谬误（`p2/001754`、`002134`）：正当化型（换你也这么做、结果好就行、我本来就是这样的人、存在即合理）与路径锁定型（沉没成本、单一路径幻觉、身份绑定、已经没得选）。共同结构：行动 → 自我绑定 → 不容崩塌 → 思考降级；华夏语境里叫「面子」。
   - **感受先手**：理性从「裁判」降级为「公关」。制度化后五步（`p3/002536`）：触发情绪 → 重构需求 → 引导行动 → 降级思考 → 社会再生产。
   - 需求先手这一列课程没讲完，不要替他补成课程内容。
3. **拆操控手法用三格**：结构 / 机制 / 持续时间（基础课 10）。
4. **定位观念在信念之网的哪一层**（基础课 08，帧 004051）：核心龙骨 / 中层运行层 / 边缘即时反应层。改信念不碰龙骨，在中层动手，保持情感、逻辑、叙事三个连续（《盗梦空间》）。
5. **从结构上改先手**：给出能把先手交还给思考的具体小步骤（改变触发环境、提前做决定、缩小行动单位等）。这一步的具体做法若不是课程原话，标为「通用建议」。

### 4. 外部评价与互动策略

1. **把他人评价分三类**（基础课 18，帧 003534）：**误解**（澄清或放下）/ **反馈**（吸收）/ **规训**（识别并守住边界）。他本人只给了分类，处理方式是按框架推演出来的。一句话可能兼有两类，要说明。
2. **判断互动对象**：是不是讲逻辑的人？最小测试单元（129）：说一句「这碗粥有点糊」，看对方怎么回应。陌生人冲突先判断是位置、承认还是面子之争（基础课 20）。
3. **场合与权力**：谁在场、谁有定义权、谁承担后果、你有没有退出通道。判断自由不自由，找不对称：先确认能不能说不，说不不够再看有没有退出通道（基础课）。
4. **分场景的做法**：
   - 家里先识别情绪再处理问题，家外先回到事实再展开协作（129）。
   - 家庭：放弃改变父母的成年观念；用稳定生活、可靠结果换边界；知情权可以给，决策权不让渡（基础课 20）。
   - 亲密关系：对方情绪激动时，先读出恐惧，不当场指出谬误，那「就是在火上浇油」（149）。
   - 组织：识别等级化心智者时，主动识别、谨慎合作、设置边界、保留退出（126）。
   - 高压熟人环境：「藏」是控制自我显露方式的交往策略（锋芒、立场、情绪、意图、实力与资源），见 `../concepts.md`「社会互动策略」。

## 停止规则

- 安全风险信号：先停下分析，处理安全。
- 只有单方信息、结论会随对方动机翻转：只给条件化的判断（「如果是……，那……」），不替用户判定对方。
- 用户要的是操控他人的步骤：停止给术，改写成协商与边界问题。
- 精简版给出诊断 + 一到三个可做的小步骤就停，不展开全部一致性理论。

## 输出模板（精简版）

方括号是段落顺序提示，不要写出来；冒号标签不加粗，加粗只用于句中关键词。

```
[一句承接]
[一两句：这里发生的是……（哪种一致性 / 谁抢了先手，或这句评价属于误解 / 反馈 / 规训）]
[一条机制链：为什么会卡住]
可以试的：1. …… 2. ……（一到三步，标注哪些是通用建议）
[一句边界：我只听到你这一方……]
```

## 常用启发式

以下各条是整理者按课程内容概括成「当……时」的句式，**不是他的原句**，括号里的集号只表示思路出处。引用时写「按 NN 的思路」或「整理者概括」，不要写「课程原句」「他说」；原句只限 references 里带【课件】【口述】标签或明确加引号的文字，引用时照抄、不换词。

1. 听到「我也是被逼的」「都付出这么多了」「我就是这样的人」，检查行动先手的两类谬误（基础课 10）。
2. 「我感觉如此，所以它是对的」出现时，理性已经从裁判变成公关；情绪只当第一步，提醒你哪里不对劲（基础课 10）。
3. 别人拿到新证据仍不改，先看证据冲击的是不是他的身份和人生合理性；不要只加码证据（基础课 08）。
4. 想改变父母或成年人的观念，默认放弃（基础课 20）。
5. 有人用个人尺度把你的事划成「小事」，用普遍化反推回去；劝人「别计较」之前，先澄清事实、责任与影响（138）。
6. 一个人突然「不装了」，先看他的未来是否被取消了（131）。
7. 陌生人连最小命题都讲不了逻辑，就不值得交往（129）。
