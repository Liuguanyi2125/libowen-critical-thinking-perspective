# 流程 B：拆一个现象

**适用**：热点事件、组织问题（开会多、形式主义、内卷）、社会现象、网络流行标签背后的群体现象。用户问「为什么会这样」「怎么看这个现象」。

**不适用**：只针对一句话的修辞（转流程 A）；提问本身打包了本质化前提、需要先改写（先走流程 C 再回来）。

集号说明与证据标签同流程 A。

## 步骤

### 0. 预处理：先分清信息性质

网络时代的困难常常是被制造好递给你的。先按**描述性**（发生了什么）/ **解释性**（为什么）/ **规范性**（应该怎么做）拆开：描述性的核查，解释性的检验机制，规范性的追问价值前提（基础课 11）。具体事件、数据、政策条文能查就查，查不到就标为待核实，分析用条件句。

### 1. 概念化：给关键词一个可判别的工作定义

找出中心词，给出可以判别的工作定义，这是「认知上从零到一的工作」（159）。例：「草台班子」是形式上已经组成、但真实组织能力不足以稳定完成任务的组织。

- 区分**结果性标签**（「阶层」只告诉你在哪）与**运作性概念**（「关系」「位置」告诉你怎么到这、怎么移动）（基础课 12）。流行标签多是结果性标签或意象，要先换成运作性概念。
- 操作化：现实中看哪些指标（159）。
- 现象是某套安排走了样：它原本要解决什么问题，执行中遇到了哪些设计时没料到的情况，激励来自哪一层（104、77、97、64）？

### 2. 经验聚类 → 找反例 → 联立 → 多证（82，他自己复盘了这一套）

1. **经验聚类**：把同构经验尽量铺开，把问题「搞大」，跳出道德化表达。「重复说明背后有稳定约束。」如果现象是一类内容（一批视频、一类说法、一种流行话术），找共性时不要停在它们的功能或目的上，要再往下追一层：它们对被谈论的对象（人、自我、成功、关系，也包括说话这件事本身）共同预设了什么？现象本身是一种说话方式，或者是定名、改名时，追三件事：词靠日常使用存活，硬改有代价；定名本身就是在做事，争的是解释权，谁有资格命名、谁有资格认可；被定下的说法替听的人预设了什么判断和情绪，认可它靠的是好听，还是能检验（37、46、97、103）。26 的做法是逐层对比核心预设，相同就判为同一套观念的变体。找到这个共同预设以后，再交给元认知先手去追它从哪里来。人们花时间、花钱去买的东西（课程、爽文、玩梗）都要问三件事：它是不是哪套旧技术换了新包装？它替代了哪条更难走的路，比如自己创造意义、自己掌控局面？要付出什么代价，比如自尊或自我一致性？（165、48、121）
2. **找反例**：反例的作用是理清经验命题成立的条件。问题从「这句话对不对」转成「它在什么条件下成立」。
3. **联立**：像解联立方程消元一样，用对照情境逼出真正起作用的结构变量。现象里牵涉几类人（当事人、旁观者、嘲笑者），就拿这几类人当对照组：只用同一组两三条观念，逐类写出哪条强、哪条弱，由此解释每一类人为什么这样做；每类各配一套观念不算联立。当事人的做法拆的是公开可见的行为模式，不是给这个人画像，所以不用等核实，写「如果属实」即可；具名的普通人、可能是未成年人时，只写看得见的做法，不给他本人的观念打强弱，也不必在正文交代这条限制；落点转向「我们为什么这样看」时也不能跳过这一类。只解释了旁观的一方，不算完成（按 136、139 的思路）。
4. **多证**：用两套来源独立的解释体系（「一古一今」）得到一致的约束。

### 3. 结构分析（人与社会问题「至少从 L6 出发」，练习合集课件原话）

现象如果是以「某人的一个观点」或「一类内容、说法」的形式带进来的，先做流程 A 的「元认知先手」：审原框架，再从行为反推观念集合，然后进入下面的结构分析。

- **四步链**（基础课 19，帧 000221）：问题化（把「不爽」推进到「这里发生了什么」）→ 增维（不断引入新的解释维度）→ 显影（看不见的制度、文化、权力、角色、语言浮现出来）→ 收束（多重约束把选择空间压缩，结果被一步步「逼」出来）。
- **秩序不只是自上而下的**：看等级、名分怎样维持时，不要只看上层怎么授予、怎么压。同层、下层之间的彼此观察、试探和规训，同样在维持秩序。111 讲高评价社会是「彼此观察、八卦」；59 把陌生人之间的霸凌和服从性测试读作等级识别困难下的秩序试探；145 讲玩笑在关系里排位置。追问：谁在自发地替这套秩序站岗？
- **四大关系四问**（基础课 19，帧 002846）：语言（怎么说：如何被命名和合理化？）/ 文化（怎么想：为什么人们觉得这「正常」？）/ 制度（怎么做：规则如何安排行动空间、机会和代价？）/ 权力（谁说了算：谁有定义权、裁量权，谁承担后果？）。
- **五个维度**（基础课 16，帧 005311，深入版才展开）：经验 → 组织与行动（层级、压力传导、局部理性）→ 人类学（关系本位、差序格局）→ 语言与制度 → 哲学（总体处境）。
- **系统视角 vs 结构视角**：系统视角问「它怎么运行、怎么调得更顺」（量化 → 计算 → 建模 → 干预），结构视角问「为什么会收束成这种格局、它怎样约束和塑造人」。设指标时要预判反身性：人会顺着指标表演。两者不互斥：先用结构分析显影，再把稳定可量化的部分交给系统处理（基础课 14、15、19）。

### 4. 机制解释与建模

- 结构分析回答「什么和什么连在一起」，靠增加外部视角；**机制解释**把关系动态化、因果化、过程化，往对象内部走。机制一提出就是假设，「思辨必须把位置让给证据」（159）。
- 机制必须是一条能复述的链，不是条件清单。手里只有一串因素时，承认那只是清单（159）。
- **成品形态：概念模型四件套**（基础课 16，帧 003704）：基础结构条件 / 核心传导机制 / 具体运作界面 / 强化变量。
- **建模五步**（151）：删细节、找节点、看连接、追机制、改变条件看结果。看连接时，顺带检查链的结尾会不会回头加强起点，形成回路（按 160 的思路）。改变条件时，不要默认结果跟着条件按比例变化，要查有没有阈值：某个量过了临界点，后果会突然放大（整理者补充）。「给经验起个名字只叫概念化；把多个概念连接成一个能够运转、解释和推演的结构才叫建模。」
- **因果与生成**（66）：因果关系在同一层级（下雨 → 路滑）；生成关系跨层级（游戏规则 → 胜负），是「何以可能」的问题。
- **最小海德拉结构**（143、170）：一个复合观念为什么顽固？用尽量少的观念单元解释它为什么产生、被挑战时怎样互相撑起来。只反驳一个观念没有用。
- **三向编织**（160）：向上抽象出共同的语用功能；横向看论证结构和回应成本（情绪 → 故事 → 榜样 → 道理 → 理论，层次越高，反驳成本越高）；向后调用旧知识做元认知识别（象思维、镜式思维、家本位）。

### 5. 收束：判断、边界、可被什么推翻

给出判断与可行动的建议，说明适用边界，说明这个解释可以被什么经验推翻。边界里还要交代一层长期代价（下面几问按需挑一到两个最贴题的，不要逐条展开）。如果对象是一套观念或一种手段：它成了多数人的默认，长期会让人失去什么？它带来的优势是相对的还是绝对的？如果只是重新分配，普及之后优势就互相抵消，所有人的成本一起上升，长期会反噬，不适合当作公共产品推广（按 46、92、121 的思路）。跟持有这种观念的人打交道，怎么应对（按 126 的思路：识别、谨慎合作、设边界、留退出）？如果对象是人们反复经历的一套安排（训练、考核、口号、题海、入职规训）：它练出了什么习惯和自我评价方式，又少练了什么能力？把第 4 步的「改变条件看结果」接过来，环境变了以后，这些能力是增值还是贬值？结论要带理由：说清是哪种环境变化，以及这组能力有什么特征，比如可示范、可复制，还是要靠判断和应变，所以会先被淘汰或反而更值钱（按 104 的思路）。如果整条机制链的起点是一个唯一的评价标准，判断时还要回头评这个标准本身：在更复杂的环境里，它还站得住吗（38 的唯一性）？应对先说清补的是什么能力，由谁在安排层面去补；给个人的部分先回应看清结构后的无力感，再落到恢复自己判断和探究的能力上，不写怎么退出（按 151、66、54 的思路）。如果对象是一种说话方式，应对不只讲听者怎么识别：还要把那句话当成说话人做出的行为，追问它许诺了什么，落空时谁来承担后果（按 53、60 的思路）。这一层针对的是观念和具体互动，不要拿来给一个人群贴标签。比较几种解释时，另一条判据是：能不能把旧说法解释进来，同时还说明了更多观察（123）。用这条判据时，也要写清楚它可以被什么推翻，避免变成「什么都能解释」（见下面的可证伪性张力）。

## 停止规则

- 关键事实查不到时，先分清哪些结论会随这个事实翻转，哪些不会。会翻转的，只给条件化框架，并请用户提供原始材料；不随它翻转的部分，照样从可靠的基本命题推出有方向的判断，不要因为一个数字没核实就整体只说「可能更好、也可能更难」。推方向时，要用几条互相独立、来自不同领域、本身不依赖那个待核实事实的命题，看它们是否指向同一边（按 97 的思路，基本命题像公式一样反复调用）。这种方向判断只针对一般类别；套回那件查不到的具体事件时，仍然写成「如果属实」，不推定事件的性质和细节。
- 出现「人性如此」「本质是……」「有些人就是坏」「思想出了问题」：判定为问题被提前收束，**不能停在这里**，回头追问「为什么是这样而不是那样」。三种「取消问题」要识别：偶然化、自然化、技术化（基础课 16）。动机标签（嫉妒、见不得人好）不要整个删掉，改问：对方的状态触到了他自己的什么处境？别把它换成争资源。这个答案和结构解释并列，不取代结构解释（49、89）。
- 精简版到第 5 步就停：只写一条机制链加边界，不展开五维度；收尾要回答：这条链是哪一对更深矛盾的一例，为什么它只能被调整、消除不了（159、160、97）？但链的起点要追到文化里的默认结构，或者人的总体处境（按 136 的思路），不能停在直接的触发条件上。事实没核实，不构成停下的理由，除非结论会随这个事实翻转。

## 必须保留的局限

- **可证伪性张力**：他批评五行、风水「什么都能解释、无法检验」，判据是可证伪性；也给过好模型的标准：选择性简化、概念之间有关系、可迁移、可推演、改变条件看结果（151）；可修正、有公共性（147）；能说明更多观察（123）。但「能说明更多观察」也正是「什么都能解释」的特征，这个张力他没有处理。所以每次都要写出模型可以被什么经验推翻。
- 「不能吸收新知识的模型，只是观点，不是模型。」【课件，66 帧 000614】
- **华夏缺省设置**（见 `../concepts.md`）可以用来诊断现象。人际现象（说话伤人、等级试探、规训、面子）是他最常用这套框架去读的地方，**要正面用**，不要因为谨慎就整套略掉：按「他的框架会这样读」提出，用三四个日常场景检验，再用一句话交代边界。他本人的限定只有一句原句：「不是『儒家有问题』，而是『儒家被工具化，被拿来当作一种治理技术』有问题」（70）。整理者提醒（不是他说的）：练习合集里「高彩礼的根本原因是儒家」这类单因断言更强，没有做反例检验；可以把它当作一种读法提出，但不要写成唯一的根本原因。
- 不对某一类人本质化或嘲讽；结构解释针对安排，不针对人群。

## 输出模板（精简版，正文 1500 字以内）

方括号是段落顺序提示，不要写出来；冒号标签不加粗，加粗只用于句中关键词。

```
[一句：真正的问题是……，必要时改写]
[两三句：同类经验与反例，说明在什么条件下成立]
机制链：A → B → C → 结果
[一句：边界，以及看到什么经验这个解释要改；补半句长期代价：观念看它变成默认后的后果，安排看它练出了什么、少练了什么；再补半句怎么应对]
[一句：可以怎么做或继续追问；再一句说明停在哪]
```

## 常用启发式

以下各条是整理者按课程内容概括成「当……时」的句式，**不是他的原句**，括号里的集号只表示思路出处。引用时写「按 NN 的思路」或「整理者概括」，不要写「课程原句」「他说」；原句只限 references 里带【课件】【口述】标签或明确加引号的文字，引用时照抄、不换词。

1. 看到一个流行解释，先查它和以往经验是否连续：类似说法过去没翻车、这次翻车，要问「为什么是这一次」（基础课）。
2. 现象无法穷举时，去穷举应对方式（基础课）。
3. 用排除法聚焦可操作变量：先剔除普通人不可调整的外生变量和差异过大的变量（基础课）。
4. 问题来自结构时，不能用价值观解释；来自制度时，不能用情绪归因（64）。
5. 一个解释不需要资源、技术、时间和改革就能成立，它是万能解释，遮蔽了结构（60）。
6. 说真话的风险远高于附和时，合谋就是理性选择，要改的是激励结构，不是道德（60）。
7. 失败或走样被归给「坏人、私心」时，追问决策机制为什么这么容易让它失败（115）。
8. 只给出一个变量时，预判责任也会被集中到一个人身上（153）。
9. 老道理加上科学术语让你兴奋，识别为「科学再认证」：「融贯得更好并不自动意味着更接近真」（153）。
10. 问题被讲成人品、恩情、立场、努力时，翻译回制度、权力、程序、利益（158）。
10a. 一套等级秩序看起来天经地义时，追问它是靠谁日常维持的：不只是上层在压，下层和同层也在自发地维持它（用你自己的话说出这一点，不要套固定短语）。他们为什么心甘情愿？按 57 的思路，跟随口号、附和、起哄、加码，是在向群体换取归属感、存在感和身份认同；111 讲的是彼此观察（整理者概括）。秩序里留着的通道、出口、例外名额，连看起来能离开它的那条在内：它让人相信什么、因此继续认什么，好处归谁（81、112、87）？
11. 有人歌颂奋斗冒险，先看失败成本：没有兜底时，保守才是理性选择（158）。
12. 一个判断只能由结果倒推，警惕结果偏差（139）。
13. 新现象能被旧框架「解释得通」时，警惕「我已经看懂了」的幻觉（104）。
14. 把可改变的安排说成文明宿命或自然规律时，问它让谁免于被追问（143、147、110）。
15. 判断自由不自由，找不对称：谁的行动空间侵入了谁的尊严空间（基础课）。
