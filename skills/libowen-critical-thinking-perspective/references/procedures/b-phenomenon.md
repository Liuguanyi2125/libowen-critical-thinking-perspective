# 流程 B：拆一个现象

**适用**：热点事件、组织问题（开会多、形式主义、内卷）、社会现象、网络流行标签背后的群体现象。用户问「为什么会这样」「怎么看这个现象」。

**不适用**：只针对一句话的修辞（转流程 A）；提问本身打包了本质化前提、需要先改写（先走流程 C 再回来）。

集号说明与证据标签同流程 A。

## 步骤

### 0. 预处理：先分清信息性质

网络时代的困难常常是被制造好递给你的。先按**描述性**（发生了什么）/ **解释性**（为什么）/ **规范性**（应该怎么做）拆开：描述性的核查，解释性的检验机制，规范性的追问价值前提（基础课 11）。具体事件、数据、政策条文能查就查，查不到就标为待核实，分析用条件句。

### 1. 概念化：给关键词一个可判别的工作定义

找出中心词，给出可以判别的工作定义，这是「认知上从零到一的工作」（159）。例：「草台班子」是形式上已经组成、但真实组织能力不足以稳定完成任务的组织。

- 区分**结果性标签**（「阶层」只告诉你在哪）与**运作性概念**（「关系」「位置」告诉你怎么到这、怎么移动）（基础课 12）。流行标签多是结果性标签或意象，要先换成运作性概念。
- 操作化：现实中看哪些指标（159）。

### 2. 经验聚类 → 找反例 → 联立 → 多证（82，他自己复盘了这一套）

1. **经验聚类**：把同构经验尽量铺开（洗碗效应、鞭打快牛、六年级现象），把问题「搞大」，跳出道德化表达。「重复说明背后有稳定约束。」
2. **找反例**：反例的作用是理清经验命题成立的条件。问题从「这句话对不对」转成「它在什么条件下成立」。
3. **联立**：像解联立方程消元一样，用对照情境逼出真正起作用的结构变量。
4. **多证**：用两套来源独立的解释体系（「一古一今」）得到一致的约束。

### 3. 结构分析（人与社会问题「至少从 L6 出发」，练习合集课件原话）

现象如果是以「某人的一个观点」的形式带进来的（比如「只要学会共情就能避免无意伤害」），先做流程 A 的「元认知先手」：审原观点的框架，再从行为反推观念集合，然后进入下面的结构分析。

- **四步链**（基础课 19，帧 000221）：问题化（把「不爽」推进到「这里发生了什么」）→ 增维（不断引入新的解释维度）→ 显影（看不见的制度、文化、权力、角色、语言浮现出来）→ 收束（多重约束把选择空间压缩，结果被一步步「逼」出来）。
- **四大关系四问**（基础课 19，帧 002846）：语言（怎么说：如何被命名和合理化？）/ 文化（怎么想：为什么人们觉得这「正常」？）/ 制度（怎么做：规则如何安排行动空间、机会和代价？）/ 权力（谁说了算：谁有定义权、裁量权，谁承担后果？）。
- **五个维度**（基础课 16，帧 005311，深入版才展开）：经验 → 组织与行动（层级、压力传导、局部理性）→ 人类学（关系本位、差序格局）→ 语言与制度 → 哲学（总体处境）。
- **系统视角 vs 结构视角**：系统视角问「它怎么运行、怎么调得更顺」（量化 → 计算 → 建模 → 干预），结构视角问「为什么会收束成这种格局、它怎样约束和塑造人」。设指标时要预判反身性：人会顺着指标表演。两者不互斥：先用结构分析显影，再把稳定可量化的部分交给系统处理（基础课 14、15、19）。

### 4. 机制解释与建模

- 结构分析回答「什么和什么连在一起」，靠增加外部视角；**机制解释**把关系动态化、因果化、过程化，往对象内部走。机制一提出就是假设，「思辨必须把位置让给证据」（159）。
- 机制必须是一条能复述的链，不是条件清单。手里只有一串因素时，承认那只是清单（159）。
- **成品形态：概念模型四件套**（基础课 16，帧 003704）：基础结构条件 / 核心传导机制 / 具体运作界面 / 强化变量。
- **建模五步**（151）：删细节、找节点、看连接、追机制、改变条件看结果。「给经验起个名字只叫概念化；把多个概念连接成一个能够运转、解释和推演的结构才叫建模。」
- **因果与生成**（66）：因果关系在同一层级（下雨 → 路滑）；生成关系跨层级（游戏规则 → 胜负），是「何以可能」的问题。
- **最小海德拉结构**（143、170）：一个复合观念为什么顽固？用尽量少的观念单元解释它为什么产生、被挑战时怎样互相撑起来。只反驳一个观念没有用。
- **三向编织**（160）：向上抽象出共同的语用功能；横向看论证结构和回应成本（情绪 → 故事 → 榜样 → 道理 → 理论，层次越高，反驳成本越高）；向后调用旧知识做元认知识别（象思维、镜式思维、家本位）。

### 5. 收束：判断、边界、可被什么推翻

给出判断与可行动的建议，说明适用边界，说明这个解释可以被什么经验推翻。

## 停止规则

- 关键事实查不到、且分析结论会随事实翻转：只给条件化框架，请用户提供原始材料，不往下推机制。
- 出现「人性如此」「本质是……」「有些人就是坏」「思想出了问题」：判定为问题被提前收束，**不能停在这里**，回头追问「为什么是这样而不是那样」。三种「取消问题」要识别：偶然化、自然化、技术化（基础课 19）。
- 精简版到第 5 步就停：一条机制链 + 边界，不再展开五维度。

## 必须保留的局限

- **可证伪性张力**：他批评五行、风水「什么都能解释、无法检验」，判据是可证伪性；也给过好模型的标准：选择性简化、概念之间有关系、可迁移、可推演、改变条件看结果（151）；可修正、有公共性（147）；能说明更多观察（123）。但「能说明更多观察」也正是「什么都能解释」的特征，这个张力他没有处理。所以每次都要写出模型可以被什么经验推翻。
- 「不能吸收新知识的模型，只是观点，不是模型。」【课件，66 帧 000614】
- **华夏缺省设置**（见 `../concepts.md`）可以用来诊断现象。人际现象（说话伤人、等级试探、规训、面子）是他最常用这套框架去读的地方，**要正面用**，不要因为谨慎就整套略掉：按「他的框架会这样读」提出，用三四个日常场景检验，再用一句话交代边界。他本人的限定只有一句原句：「不是『儒家有问题』，而是『儒家被工具化，被拿来当作一种治理技术』有问题」（70）。整理者提醒（不是他说的）：练习合集里「高彩礼的根本原因是儒家」这类单因断言更强，没有做反例检验；可以把它当作一种读法提出，但不要写成唯一的根本原因。
- 不对某一类人本质化或嘲讽；结构解释针对安排，不针对人群。

## 输出模板（精简版，正文 1500 字以内）

方括号是段落顺序提示，不要写出来；冒号标签不加粗，加粗只用于句中关键词。

```
[一句：真正的问题是……，必要时改写]
[两三句：同类经验与反例，说明在什么条件下成立]
机制链：A → B → C → 结果
[一句：边界，以及看到什么经验这个解释要改]
[一句：可以怎么做或继续追问；再一句说明停在哪]
```

## 常用启发式

以下各条是整理者按课程内容概括成「当……时」的句式，**不是他的原句**，括号里的集号只表示思路出处。引用时写「按 NN 的思路」或「整理者概括」，不要写「课程原句」「他说」；原句只限 references 里带【课件】【口述】标签或明确加引号的文字，引用时照抄、不换词。

1. 看到一个流行解释，先查它和以往经验是否连续：类似说法过去没翻车、这次翻车，要问「为什么是这一次」（基础课）。
2. 现象无法穷举时，去穷举应对方式（基础课）。
3. 用排除法聚焦可操作变量：先剔除普通人不可调整的外生变量和差异过大的变量（基础课）。
4. 问题来自结构时，不能用价值观解释；来自制度时，不能用情绪归因（64）。
5. 一个解释不需要资源、技术、时间和改革就能成立，它是万能解释，遮蔽了结构（60）。
6. 说真话的风险远高于附和时，合谋就是理性选择，要改的是激励结构，不是道德（60）。
7. 失败被归给「坏人、内鬼」时，追问决策机制为什么这么容易让它失败（115）。
8. 只给出一个变量时，预判责任也会被集中到一个人身上（153）。
9. 老道理加上科学术语让你兴奋，识别为「科学再认证」：「融贯得更好并不自动意味着更接近真」（153）。
10. 问题被讲成人品、恩情、立场、努力时，翻译回制度、权力、程序、利益（158）。
11. 有人歌颂奋斗冒险，先看失败成本：没有兜底时，保守才是理性选择（158）。
12. 一个判断只能由结果倒推，警惕结果偏差（139）。
13. 所有人都看到同一个机会时，它往往已经不是机会（92）。
14. 新现象能被旧框架「解释得通」时，警惕「我已经看懂了」的幻觉（104）。
15. 把可改变的安排说成文明宿命或自然规律时，问它让谁免于被追问（143、147、110）。
16. 判断自由不自由，找不对称：谁的行动空间侵入了谁的尊严空间（基础课）。
