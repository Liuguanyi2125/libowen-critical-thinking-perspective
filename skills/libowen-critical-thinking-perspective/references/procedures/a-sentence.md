# 流程 A：拆一句话

**适用**：金句、口号、热评、俗语、领导或家人的一句话、标题党句子。用户说「拆一下这句话」「这句话哪里不对」。

**不适用**：用户给的是自己要改的一整段论证或文章（转流程 E；别人的论证、台词、辩论仍走这里）；用户要的是这句话背后的社会现象（转流程 B）。

集号一律是《批判性思维练习》合集的本地目录号（见 `../research/01-course-map.md`）。证据标签：【课件】课件原文，【口述】他口头说的，【推断】整理者归纳。

## 步骤

这是练习合集最稳定的骨架（「批判性思维关心××」）。他每集从下表挑 4–6 项，按顺序分段讲；精简版挑 3–5 项。各集完整目录见 50（帧 000103）、84（课件 1/5–5/5）、44（000131）、41（000200）。

| 顺序 | 关心什么 | 要问的问题 |
|---|---|---|
| 0 | 先说结论 | 一句话交代这句话的问题在哪 |
| 1 | 概念清晰 | 关键词是意象还是概念？有没有范畴错误？（11、52、99） |
| 2 | 语用 | 这句话在关系里拿来做什么？语用收益归谁？ |
| 3 | 逻辑谬误 | 逐步写出推理链，逐条判断（58 给推理编号 ①–⑧，逐个打 ×） |
| 4 | 预设 | 它偷偷默认了什么？ |
| 5 | 论证结构 / 理论结构 | 重构前提和结论；背后是哪种世界观？用可证伪性检验一遍（84） |
| 6 | 语境、权力结构 | 这句话在什么语境下产生？谁有权定义？（57、44） |
| 7 | 元认知 | 说话方式暴露了哪种文化传统或观念集合？（84） |
| 8 | 生活实践、替代思路 | 换成什么说法、什么做法更好？（41、53、122） |

**先看逻辑，再谈内容**【课件，106 帧 000423】：审题 → 审理（只要范畴错了，后面内容再多也是浪费）→ 查谬误 → 再决定要不要进入知识细节。「不要和不讲逻辑的人辩论内容。」108 把这一步叫「先验层次」：先不核查事实，只看这个说法在形式上能不能成立。

清单里的「元认知」在这里只是分段标签（113、115、124、126、139），不能当作 L9 层的证据。

### 元认知先手（句子在给人际或社会现象归因、开药方时必做）

句子在解释一类人际或社会现象、或给它开药方时（「只要……就能」「××是因为××」「人性如此」「说到底就是……」），先写第 0 项结论，然后做这一步，再进清单。这一步不受停止规则影响。他分析这类句子，常常先推翻原句的提问框架，再把行为读成某种观念在运作。

1. **审原句的框架**：原句把问题放在哪个二分上（有意 / 无意、天性 / 后天、个人修养 / 外部环境）？这个二分本身站得住吗？依据：165 课件第③条「否定人性解释：不是天性如此，而是文化塑造」；77 先问「这句话在关系中干什么用」。
2. **反推观念集合**：「我们应该通过一个人的语言，去把握一个人头脑中的观念集合」（74）。这种说法为什么能不假思索地说出口？说话者在上下位关系里处在哪一层？当原则普遍化后，代价落到他自己一方哪一层人身上（62、138、129）？几方争论时，占理一方里谁只是宾语，它的好意要兑现得先满足什么条件（26、166）？
3. **按句子的形态选观念来源**：先看它怎么说，再看它说什么事。选定一行后，读 `a-metacog-detail.md` 里对应的那一节。

| 形态 | 主动作 | 落点 |
|---|---|---|
| ① 画面、比喻、拟人、隐含类比代替机制 | 象思维（基础课 01）；关键词没有可判别含义：给的是感受和立场，不是知识（84）；短句俗语先认它压缩的经验，再看缺什么（103、131）；拟人化拆回具体部门（153） | 这样说话的长期后果，以及换成概念化表达能说清什么 |
| ② 按位置、资历、名分排序，或在关系里试探、规训 | 关系本位、等级与名分、礼的规训（59）；前提是说法里有这类线索 | 「用逻辑代替身份」（基础课 02） |
| ③ 评价别人的人生、选择、归属 | 中心投射（160）；**必须做换位**：换的是评价者，不是场景。把说这话的人换成父母或上级，被评价的人换成孩子或下属，然后明说这句话变成了「我比你更知道什么对你好」（26）；问对方守护的是伦理还是秩序感（95）；被评价方自己的说法也要拆（86、47） | 替代看法：对方不需要用我们的标准证明自己；不花篇幅核查当事人的经历 |
| ④ 流行语被拿来解释一切，或给自己的状态命名 | 情绪容器还是立场标签（81）、认知本能（35）、单因替换检验（147）；自我命名的词放回动词用法里还原（48） | 我们为什么这样说，这个词挡住了什么 |
| ⑤ 号称闭环、概念清楚的理论或世界观（满篇画面词的归 ①） | 先查被比「谁更根本、谁派生谁」的概念是否同范畴、同层级（106、52），错位就停；对得上再承认自洽，上升到元层面（86、17）→ 诊断说服力从哪来（35、113） | 回到我们自己的问题意识（146） |

   几种形态同时出现时，都写，最多写两种，对应的几节都要读。句子表面是一串画面或比喻时，① 必选。哪种都不像时，换别的观念来源，比如受害者话语（50）。不管选哪种，都按「他的框架会这样读」提出，再用一句话交代：哪些情境下这种读法不成立。
4. **用两三个日常同构场景检验**，标「举例」。
5. **落点和诊断对应**：对策型、替代看法型、回到读者型，三选一（细节见 `a-metacog-detail.md` 末节）。原句开的药方如果是个人修养，先说明它为什么够不着上面的机制。

**篇幅**：精简版里，这一步压成四到六句（框架一句，来源和主动作两句，场景一句，落点一句），之后清单只再挑一两项。不要复述规则里的条件句，比如「这句话是在劝一类人……」，直接做判断。

### 各项的具体做法

**语义收益与语用收益（112）**：先问这句话带来了什么新信息（语义收益），再列它的语用收益，最后问「收益归谁，短期谁得利，长期谁受损」。

- 语义空转的四种句型：逻辑冗余、同义反复或概念空转、伪解释、指令冲突。
- 常见语用收益【课件】：身份地位、压制讨论、营造氛围、掩盖问题、短期维稳、维护人设。他口头还补充了：情绪安抚或关怀表演、延迟满足（把结构问题翻译成个人修养）、动员、免责。
- 情绪价值的边界【课件，112】：只在家庭和亲密关系里合理；在社会场景里，它只会遮蔽边界、权责、报酬和规则。

**预设连续显化（62）**：「预设，是语言进入世界之前，偷偷塞进去的条件包。」【课件】对同一个命题连续追问六次预设，每次把一个预设翻译成可以观察的行为属性。

**言语行为与名实（88、46、81）**：

- 「劳动最光荣」是宣告类言语行为，作用像赋值；「不好好学习就和他们一样」是指令类，起规训作用（88）。
- 名实张力（46）：「名」自上而下、固定不变，「实」自下而上、不断流动。「追逐对名的符合，是一切形式主义的最底层逻辑。」
- 按功能判断对象，不按名称判断（81）。

**反驳价值判断（166）**：

1. 先分开事实判断和价值判断。
2. 识别价值句的规训性：「应当」句是在给关系赋值。
3. 【口述】「经验事实可以参与价值论证，但不能单独推出价值结论。」经验层面的战场是无限的，不要在这里攻防。
4. 先验层面的反驳：逐词拆开（「使命」是谁赋予的？），再做关键词定义两难：定义得窄，命题失去普遍性；定义得宽，命题失去信息量。

例：对方说「不工作你吃什么」，先回答「同意」，再指出这只是必要条件，只能证明工作的工具价值（166）。

**识别解释幻觉与伪知识（35、34、30、147）**：

- 解释幻觉（35）：单因解释、类比、情绪唤醒、不给证据，都比批判性思维省力。
- 伪知识的语言特征（34）：标题弱因果、正文强因果；体验语言冒充观察语言；全称量词；跨范畴术语拼贴；不可证伪。
- 「既是 A 又不是 A」的四种语用（30）：伪中立、假对立、假全面（用来结束对话）、「太偏激」式规训。
- 文学化、寓言化、象思维表达（147）：追问中介机制是谁补上的。

**评价题的欠规定性（169）**：「有没有用」「好不好」省略了四个关系项：对谁、为了什么、在什么情境、多长时间尺度。先补齐再答。

## 停止规则

- 【课件，52 帧 000517】「当一个论证在预设层面已出现系统性错误时，便没有讨论论证结构的必要」。触发时用自己的话交代停在这里，以及为什么。例外：说话方对听众握有制度或职位权力（单位、学校、官方机构、媒体），并且拿这句话给人归类、规训时，语境与权力、元认知两项不跟着停。普通网友之间互相贴标签不算例外。这条例外只决定写不写那两项，例外的条件本身不写进正文。
- 第 1 项发现范畴错误时，同样不再进入内容细节（106）；但元认知第 2 步对占理一方的追问照做。
- **停止只跳过清单后面的项，不结束回答。** 句子在给社会现象下因果判断时，停下后补两三句：一条机制链，解释句子所指的那个处境本身，而不是这句话为什么流行，用结构视角写成递进的几环（131），再写什么经验能推翻它。句子在劝某类人放弃或离开什么时（别学、别争、走掉），这条处境链照写，再用一两句追问照做的后果：照做的人处境会怎样，劝告的前提会不会因此被复制，这个说法替谁免了责？问题主要在「我们为什么这样看」时，补替代看法，不补因果链。
- 用户要「一句话」「简单说」：只给第 0 项结论，一到两句，不套清单。

## 收尾规则

不站标签，改问 HOW（52 帧 000534）：这个保护是制度性的还是情绪性的？问责、申诉、退出的通道在哪？或者给替代说法（第 8 项）。

## 常用启发式

以下各条是整理者按课程内容概括成「当……时」的句式，**不是他的原句**，括号里的集号只表示思路出处。引用时写「按 NN 的思路」或「整理者概括」，不要写「课程原句」「他说」；原句只限 references 里带【课件】【口述】标签或明确加引号的文字，引用时照抄、不换词。

1. 一句话听起来务实、成熟、难反驳，警惕它是阻断话语：拆成事实判断 + 价值排序分别检验（基础课）。138 补出机制：「小事」定性 → 「较真」定性 → 替人算成本，完成对问题的降级。
2. 一句话庄重、优美，却没有可验证内容，它的功能是仪式和安抚（53）。
3. 听到口号式指令，追问：我们是谁？什么时候完成？指标是什么？失败了怎么办？（53）
4. 一个说法的任何反例都能被解释成「时候未到」「执行不到位」，判它不可证伪（84、90）。
5. 一句话只描述效果或目标，判为空心短句，追问过程和检验标准（161）。
6. 一个说法正着说、反着说都有理，说明概念没锁死，先要求定义（159）。
7. 推理从行为跳到动机、再跳到立场，把两次跳跃标出来（115）。
8. 对一句批评的回应全在问「你是谁、有没有资格、什么动机」，这是去问题化（63）。
9. 代价被叫作「责任」「顾全大局」，还原本名：代价转移（123）。
10. 规则场景里出现「姐」「兄弟」「一家人」，识别为事实没变、关系变了（121）。
11. 有人用「周期」解释，追问周期何时到头（140）。
12. 被一个说法强烈共鸣时：「熟悉不等于真实；顺，不等于对；共鸣，不等于证明」（111）。
13. 一句话出现在关系语境里，先判断它是不是间接言语行为；按字面回应就是稻草人（127）。
