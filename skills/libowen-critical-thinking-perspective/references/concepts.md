# 概念词典

各流程用到的核心概念集中在这里。每条写：是什么、被哪个流程调用、出处、局限。概念只在流程需要时调用，不单独开讲；用户直接问某个概念时，按「简单知识问题」直接回答。

集号写法：「基础课 NN」指《批判性思维基础课》，纯数字指《批判性思维练习》本地目录号（见 `research/01-course-map.md`）。

## 观念装备栏（观念集合）

- **是什么**：人头脑里有一个由语言和文化装好的「观念装备栏」，在思维后台决定我们看见什么、感受什么、想要什么、能做什么；批判性思维（狭义）就是管理它的操作技术：**查看**（我装了什么、从哪来、还适不适合）→ **监控**（元认知）→ **更新**（有何根据？是知识还是意见？能否解释新经验？有无更可靠替代？）。
- 优先说「观念集合」；他把「三观」当作粗糙的「简约说法、模糊词汇」，并不禁用。用「观念 + 语言」替代「思维」这个超级大词。
- **对象化**：没有名字的思维方式无法观察，先命名。但「看见不等于摆脱」。
- **调用**：流程 A 第 7 项（元认知）、流程 D 第 3 步。
- **出处**：基础课 01（帧 004622）、06、21（帧 001112–003307）。
- **局限**：容易把物质条件、资源约束解释得过轻，要和结构视角配合。

## 海德拉效应 / 奇美拉效应 / 最小海德拉结构

- **海德拉效应**【课件，170 帧 001604】：观念「相互支持、相互保护，形成具有自我维持能力的解释结构。当某个观念受到质疑时，其他观念便可能提供新的解释，使原有体系免于被推翻」。所以单点反驳无效。
- **奇美拉效应**：几个观念合成一个约束力更强的新观念（基础课 01）。
- **最小海德拉结构**（143）：用尽量少的观念单元解释一种复合观念为什么产生；要满足可靠性（基本观念能推出复合观念）和稳定性（一个被挑战时其他能撑起来）。「永生之头」例：朴素经验论（26）。
- **调用**：流程 B 第 4 步；流程 A 的元认知先手在拆一套人生信条、口诀或俗语时也用。这时要分清表层说法和深层观念：表层说法会过时、被嘲笑、消失，深层观念换个说法继续活着。具体做法是：列出它和哪几个相邻观念互相支撑，说明为什么只反驳其中一个没有用（26）。

## 概念与定义

- **是什么**：「概念重要，定义不重要」：不收集现成定义，按皮尔士和杜威的实用主义意义理论，看它在实践中带来什么效果，再用排除法、近义比较、关系网络澄清（基础课 01，帧 000128–001249）。
- 新词四问：指什么？有无清晰定义？能否产生可检验的结果？对应什么行动？构词分析找中心语（基础课 13，帧 000224）。模糊大词按时间轴或视角拆开（「命」：过去 / 当下 / 未来，基础课 12）。不可定义的大词（善、公正）用摩尔策略：改问「在某情境中它意味着什么」（基础课 02）。
- **结果性标签 vs 运作性概念**（基础课 12，帧 001128）：标签只告诉你在哪，运作性概念告诉你怎么到这、怎么移动。
- **调用**：流程 A 第 1 项、流程 B 第 1 步、流程 E。
- **局限**：「定义不重要」针对的是收集现成定义的习惯。分析时仍要**自己给出可判别的工作定义**（159：「认知上从零到一的工作」）。要区分术语和黑话：可定义、可验证、可质疑的是术语。

## 杜威逻辑与思维五步法

- **是什么**：逻辑不只是形式推理有效，而是在不确定情境里「发现、建立、验证、修正关系」的整个探究过程（基础课 17，帧 003143）。思维始于经验的不连贯；他后来更正为「新经验 vs 旧解释系统」：经验不会自己冲突，冲突的是理解。
- 七类关系：外延 / 命题条件 / 相关 / 过程时序 / 整体—部分 / 功能 / 互补；「相关」只是线索，不是解释（基础课 17）。
- 信念之网 + 纽拉特之船：只能边航行边修补（基础课 08）。
- **五步法**表格见流程 C 第 6 步。**人类应对不确定世界的模型**（97）：不确定性 → 问题情境 → 试错 → 方案 → 控制 → 新的不确定性；「强者组织自己的确定性，弱者被迫消化由此带来的不确定性」（102）。
- **调用**：流程 C；流程 B 的机制检验。
- **局限**：示范课里不少推断他自己说「没有专门查证、属示范性推理」，第五步验证不能省。

## 自我一致性模型

- 三种一致性、四要素先手、两类谬误、信念之网三层：详见流程 D 第 3 步。
- 自我一致性既是**限制器**（新证据冲击的是「我过去的人生是否合理」），驾驭之后也是**增幅器**。
- 练习合集补充（131、138）：自我一致性「最终会走向封闭」，社会一致性「将继续牺牲判断的独立性和准确性」；未来被取消时，自我一致性完全压倒社会一致性。
- **出处**：基础课 06、08、10、21。
- **局限**：需求先手没讲完；神经科学数据他自己说多为转述。

## 结构视角 vs 系统视角

- 详见流程 B 第 3 步。认知策略解锁链：神话 → 本体论哲学 → 科学 → 系统论 / 社会科学 → 关系思维；因果思维解释「事件的发生」，结构思维解释「行为的可能性」（基础课 14，帧 004507）。系统思维在 L5 上限（基础课 15）。
- **资源分布场**（基础课 12，帧 002830）：「天」可以转写为场，分布不均匀、对普通人不可见；规则密度与资源密度正相关；阶层跃迁 = 在多个场里移动位置。
- **局限**：可证伪性张力，见流程 B「必须保留的局限」。

## 华夏缺省设置

- **是什么**：华夏学生头脑里默认装着一套教材没考虑的观念插件和关系结构；不先看见它，批判性思维的技巧会在真实生活里失灵。
- **象思维**是比插件更底层的认识论驱动（「以像什么代替是什么」），所有文明都经历过；问题是定义不了、用经验拼贴代替建模、只好道德化。另两个插件：感官刺激偏好、工具理性（基础课 01，帧 004604）。工具理性指只问手段是否有效、不问目的本身（按 77 的思路）。它和实用主义不同：实用主义也检验目的和后果。
- **关系本位也是应对不确定性的默认解法**：人总要寻求确定性，华夏的默认做法是去找关系，而不是去找规则（按 30、102 的思路）。
- **协作路线**：礼与关系本位（用身份、等级压住分歧，有秩序无共识）vs 批判性思维（用逻辑代替身份、证据代替地位，主体间性）（基础课 02，帧 002819）。他有时说两种，有时说三种（127 加上儒家用亲子关系组织社会）。
- **镜式思维**（基础课 03）：146 课件定义为「主体以自身既有经验、欲望与观念为先验框架，将他者纳入自我理解」。它的另一面，是借外部参照和他人的眼光来给自己定位：榜样提供的不是信息，而是人格模板，「比较本身就产生规范压力」（160）。所以「认清自己」常常等于在既定格局里认清自己的位置，并履行这个位置要求的连带责任（160），而不是去发现一个独立的自我（59：「你不是你自己，而是一个被预设好的角色」）。
- **朴素语言观**（基础课 21 名称；按 97、54 的思路）：默认说话是用来维持关系、表达感受、营造氛围的；评价一句话，看它说得到不到位、好不好听，不看它能不能被检验。拆「一种说话方式为什么流行」时，可以把它当作观念来源之一。
- **礼—修身—家—耻闭环**（基础课 20）、**名分逻辑 / 资格审查**（基础课 22）、**无自我的自我中心**（基础课 06）、托付型人格与亲情化权力。
- **民间智慧的五个缺点**（131）：侧重象思维、缺抽象、缺机制、难迁移、碎片化。
- **调用**：流程 B 第 3 步（文化、权力维度）、流程 D 第 4 步。
- **他本人的限定**（原句，只有这一句，引用时照抄）：「不是『儒家有问题』，而是『儒家被工具化，被拿来当作一种治理技术』有问题」（70）。限定的对象是儒家，不是「中国人」或任何人群。
- **整理者提醒**（不是他说的，不要挂他名下）：这是强解释框架，对儒家和中国历史的叙述多处是简化；用于诊断现象可以，不要当成史学定论，不要给具体的人或人群贴标签。

## 问题意识与未分化问题

- 知识回答「我知道什么」，能力回答「我能做什么」，问题意识回答「我们究竟遇到了什么、什么值得解决」（基础课 26）。详见流程 C。
- **审查问题 ≠ 应试审题**：审题默认题目完整正确；审查问题允许「提问者很真诚，但问题本身还没完成」。

## 伦理模型与理性协作

- **是什么**：批判性思维发明「主体间性的事物」（逻辑化、证据化的判断、知识、方案），由此产生「信」，再产生影响力；讲逻辑的人增多，协作成本下降（基础课 02，帧 004820–005718）。
- 正直是自己承担**翻译成本**；只批判不重建是「中式批判」，要「反思重建」（基础课 02）。
- 公共讨论六步分工：普通人说出问题 → 相关人士提供经验 → 专家提炼知识 → 制度回应 → 执行部门办理 → 公众监督（基础课 22，帧 002534）。
- 五个好词：讲逻辑、讲科学、讲民主、有边界感、独立思考，都是批判性思维的能力后果（基础课 18，帧 002340）。
- 2×2 博弈矩阵：批判性思维者之间理性协作最优，普通人之间靠位置、面子、人情，内耗最大（基础课 20，帧 003516）。
- **局限**：他承认「上一轮实用主义失败」在于没穿透关系本位和权力结构。

## 社会互动策略（练习合集推进的部分）

- **批判性思维 + 博弈论**（125、126）：「批判性思维分析话语的结构，博弈论分析行动的结构。」「没有博弈论的批判性思维容易停留在讲道理……没有批判性思维的博弈论也容易滑向精致利己主义。」
- **藏**（109/111）：在熟人社会的高压关系结构中，「控制自我显露方式的交往策略」；藏锋芒、立场、情绪、意图、实力与资源。
- **华夏社会压力结构模型**（111）：关系本位的角色期待 → 很累；礼的细密规训 → 很烦；熟人社会没有匿名和试错空间 → 很担心；高评价社会 → 要小心；以和为贵 → 还得忍。
- **藏、害、三德**（114）：底层藏，中层害，顶层用德性语言包装控制；用重复博弈解释为「恶性均衡」。
- **信号**（131）：信用信号「我有未来」、激励信号「你有盼头」、风险信号「你没有未来」；信号表演导致判断力集体失灵。
- **互助持续的五个条件**（125）：关系稳定、互动重复、信息透明、背叛有代价、合作有未来收益。
- **仍未解决**（131 结尾）：这些策略「必须能够在更不完美的社会环境中运行」。
- **调用**：流程 D 第 4 步。用于识别和自保，不用于操控具体的人。

## 认知层次 L0–L10

速查表。逐层判别、例子、冲突和使用规则见 `cognitive-levels.md`，引用前必须读它。

| 层 | 名称 | 典型表现 | 往上推的问句 |
|---|---|---|---|
| L0 | 本能驱动 | 刺激-反应 | 「这件事会不会发生在我身上？」 |
| L1 | 情绪驱动 | 把情绪强度当事实强度 | 「为什么他们会这样对待彼此？」 |
| L2 | 立场驱动 | 戴帽子、贴标签、站队 | 「男人/女人是不是都这样？」 |
| L3 | 教条驱动 | 用现成话语和权威替代思考 | 「这个故事是不是再次证明了某一句老话？」 |
| L4 | 本质导向 | 「××的本质是…」 | 「关键问题究竟是什么？」 |
| L5 | 逻辑导向 | 因果机制、系统思维 | 「这个所谓的关键，真的有证据吗？」 |
| L6 | 结构导向 | 关系网络、多维约束 | 「还有哪些维度被忽略了？」 |
| L7 | 语境论 | 不否认真理，只否认脱离语境的真理 | 「放进不同知识语境，会变成哪些不同的问题？」 |
| L8 | 概念反思 | 反思概念如何构造、边界在哪 | 「××何以可能？」 |
| L9 | 元认知 | 从语言反推观念集合；监控自己的偏误 | 「我们为什么会这样提问、为什么爱这种说法？」 |
| L10 | 创造 | 跨范畴经验碰撞、重组出新 | 「所有层次共享的那个前提，一定成立吗？」 |

L0–L3 是「驱动」，L4–L6 是「导向」【课件，73】。定义来自 73，L0–L8 问句来自 146 汇总表；L9、L10 两格是整理者改写，不是原话。

**使用规则**：
- 诊断的对象是「这句话或这个回答」停在哪一层，目的是往上推，不是贴标签。这是整理者定的规则：他本人在测评、组织语境里会给人分档（57、62、169），被问到时要如实说明，同时他也批评过高 / 低认知标签，两者并存。
- 层级高不等于策略更优：在组织层面，可规模化的制度（L6）优于依赖个人的元认知（L9）（71）。
- L10 他本人说「为时尚早」，原始创新只能展示、不能当方法教，不要编造训练法。可训练的是「编织」：异质材料 → 理性编织 → 公共检验（161、164），它不等于 L10。
- `cognitive-levels.md` 标【推断】的内容和你自己补的建议，要在句中写明「这是整理者推断 / 通用建议」。往上推可以跨层，但要说明跳过了哪层。
- 想检验自己的认知水平，看别人愿意把什么层次的问题交给你（基础课）。

## 其他

- **认识现实五步**（170）：描述现实 → 补全现实（图式）→ 解释现实（观察负载）→ 改变现实（探究）→ 重构现实（社会想象）。换描述语言（语文 / 商业 / 权利）就是发现新问题的开始。流程 B、E 可调用。
- **新的生成**【课件，161 帧 000747】：「新不是物的属性，而是新材料与旧知识网络发生关系后的产物。」新关系要过三关：说清楚、经他人检验、回到现实（164）。
- 专家给出判断时，查他的学科背景，反推他的默认预设（98）。
