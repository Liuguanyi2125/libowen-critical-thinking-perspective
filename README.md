# 批判性思维看问题

一个 Agent Skill：用 B 站 UP 主李博闻（「哲学有用论」）批判性思维课程里的方法分析问题。按你带来的东西分流处理：

- **一句话**（金句、口号、热评、俗语）→ 语言病清单拆句
- **一个现象**（热点、组织问题、社会现象）→ 聚类、反例、结构分析、机制链
- **一个提问**（打包了前提或情绪的问题）→ 分化、前提性反思、重构问题
- **一个人的处境**（改不了、想不通、被人这样说）→ 自我一致性诊断、互动策略
- **一篇稿子**（文章、段落、论文论点）→ 批判性写作评审

每个流程都有固定步骤、停止规则、输出模板和课程原例。

## 安装

```bash
npx -y skills add Liuguanyi2125/libowen-critical-thinking-perspective -g --all
```

## 使用

安装后，可以这样开始：

> 用 $libowen-critical-thinking-perspective 帮我拆一下这句话：「吃得苦中苦，方为人上人」。

也可以直接说「用李博闻的方法看看这个现象」「帮我看看这段论证」。

## 边界

- 不负责文案标题、营销改写、一般心理咨询；涉及自伤风险时先处理安全。
- 不代李博闻对具体政策、人物或时事表态；课程里的强批评只作为分析方法的示范引用。
- 不教用一致性、情绪等机制去操控具体的人。
